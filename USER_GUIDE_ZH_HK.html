先看結論

問題答案
沒有 Mac 可以安裝嗎？可以。只需要一部 Windows 電腦做一次性設定。
之後每次用都要接電腦嗎？不用。設定完成後，日常使用、App 更新、7 天重簽全部在 iPhone 上自動完成。
免費 Apple ID 可以用嗎？可以。簽名約 7 天到期，但 SideStore 會在 iPhone 上自動重簽，你不需要做任何事。
GFlyer 會自動更新嗎？會。有新版時 App 會自己跳出提示，按一下交給 SideStore 安裝。
要付錢嗎？不用。所有工具（SideStore、iloader、LocalDevVPN）都是免費的。
為什麼推薦 SideStore「夜晚版」？夜晚版（Nightly）是每日更新的版本，新 iOS 需要的修正通常先進夜晚版，穩定版有時落後幾個月。代價是官方不受理夜晚版的問題回報。兩版都能照本教學使用；夜晚版出狀況時，用同一個 iloader 改裝穩定版即可。
一定要建立「捷徑」嗎？不用。只有兩個選用功能需要：補錄步數、一鍵切換飛行模式。不建捷徑，GFlyer 其他功能完全不受影響（Part 9）。
每次用都要先開 LocalDevVPN 嗎？不用。按開始時如果它未連線，GFlyer 會自動切換過去開啟，約 1 秒後回來繼續。只有 SideStore 安裝或重簽時要自己開（Part 10）。
停止模擬後，其他 App 會立刻回到真實位置嗎？不一定。iOS 會沿用最後的模擬位置一段時間。要立刻還原，用 GFlyer 設定內的「完整清除模擬定位」，然後開關一次飛行模式（實測必要）。
GLOSSARY

名詞解釋：這些工具是什麼

先花兩分鐘認識會出場的角色，之後每一步你都會知道自己在做什麼。

側載（Sideload）

不經 App Store，把 App 裝進 iPhone。Apple 要求這種 App 用你自己的 Apple ID「簽名」，而免費帳號的簽名 7 天到期。

SideStore

常駐在 iPhone 上的「小型 App 商店」。它負責安裝 GFlyer、自動更新，以及每 7 天自動重簽——全部不用電腦。

iloader

Windows 上的一次性工具，用來把 SideStore 裝進 iPhone。之後就幾乎用不到電腦了。

LocalDevVPN

App Store 上的免費 App。它在 iPhone 內部建立一條「本機通道」，讓 SideStore 和 GFlyer 能連到 iPhone 自己的開發服務。它不是翻牆用的 VPN，不會改變你的上網地區。

Pairing File（配對檔）

這部 iPhone 信任電腦的憑證檔。GFlyer 的全機定位需要它。每部 iPhone 要建立自己的一份，屬於敏感檔案，不可給別人。

DDI（開發者磁碟映像）

約 16 MB 的 Apple 官方元件。GFlyer 第一次啟動定位時自動下載並驗證，之後保留在機內。

夜晚版（Nightly）

SideStore 每日自動建置的最新版本。新 iOS 需要的修正通常先出現在這裡，代價是官方不受理它的問題回報。本教學推薦它。

捷徑（Shortcuts）

iOS 內建的自動化 App。GFlyer 有兩件事（寫入健康步數、切換飛行模式）沒有 App 權限可做，改由你自建的捷徑代勞。這是選用的。

PART 2 · 只做一次

電腦端：Apple 元件與 SideStore（夜晚版）

2.1 安裝 Apple 的 Windows 元件

iloader 依賴 Apple 的 USB 驅動程式，而驅動要靠 iTunes 帶進來。注意：要用 Apple 網站版，不是 Microsoft Store 版——後者不會安裝這組驅動。

  1. 如果電腦已裝了 Microsoft Store 版的 iTunes，先到 Windows「已安裝的應用程式」把它移除。
  2. 下載並安裝 Apple 網站版 iTunes，然後重新啟動電腦。
  3. 開啟 iTunes，用 USB 線把 iPhone 接上電腦。
  4. iPhone 出現「信任此電腦？」→ 按信任，輸入 iPhone 密碼。
檢查點：iTunes 能看見你的 iPhone 才繼續。看不見的話，換一個 USB 插口或換一條線再試。

2.2 先決定裝哪一個版本

iloader 的「安裝程式」區會列出四個可以裝的版本。本教學推薦其中的夜晚版。

本教學推薦

SideStore（夜晚版）SideStore (Nightly)

夜晚版是 SideStore 每日自動建置的最新版本。新 iOS 版本需要的修正通常先進夜晚版，穩定版有時要等幾個月才跟上——這對側載工具很關鍵，因為 Apple 每次系統更新都可能改動它依賴的介面。

iloader 的中文字樣英文介面要不要選
SideStore（穩定版）SideStore (Stable)可以用，但更新較慢
SideStore（夜晚版）SideStore (Nightly)選這個
LiveContainer + SideStore（穩定版）LiveContainer + SideStore (Stable)不需要
LiveContainer + SideStore（夜晚版）LiveContainer + SideStore (Nightly)不需要

LiveContainer 是另一個工具，讓你在一個側載名額裡跑多個 App。GFlyer 用不到它，少一層東西比較容易排查問題。你如果為了別的 App 想省名額而選了帶 LiveContainer 的版本，本教學其餘步驟一樣適用。

夜晚版的代價，先說清楚SideStore 官方對一般使用者的建議是穩定版，夜晚版遇到的問題官方不受理。如果夜晚版在你的機上不穩，用同一個 iloader 改揀「SideStore（穩定版）」重裝一次即可，資料一般會保留（官方不保證，重要資料先在 GFlyer 匯出備份檔）。

2.3 用 iloader 安裝

Windows 用這一個：iloader-windows-x64.exe（約 5.8 MB，點下去就開始下載）。

想自己到官方頁面找？官方只有兩個地方：GitHub 的 nab138/iloader releases 頁 與 iloader.app（Homebrew、AUR 等是社群維護，非官方）。releases 頁一次列出二十幾個檔案，包括 macOS 和 Linux 的，很容易點錯。認這兩點就不會：檔名要有 windows-x64，而且不能以 .sig 結尾（那是簽章檔，每個安裝檔旁邊都有一個，不是程式）。想用 iloader-windows-x64.msi 也可以，兩者裝出來一樣。
  1. 開啟 iloader。介面語言可以自己切換；下面每一步都同時列出中文與英文字樣，你看到哪一種都對得上。
  2. 在「帳戶」Account 區登入你自己的 Apple ID，照提示輸入雙重認證碼。
  3. iPhone 用 USB 接上電腦並解鎖。在「管理」區按 重新整理裝置Refresh Devices，再從 揀裝置Select a device 選你的 iPhone。
  4. 捲到「安裝程式」Installers 區，在 揀版本Choose a build 選 SideStore（夜晚版）。
  5. iloader 會依序跑三個步驟，畫面上看得到進度：下載 SideStore → 簽署同安裝 SideStore → 放入配對檔案。 最後一步是 iloader 自動把配對檔寫進 SideStore 的容器裡——這正是日後最常見那個 UDID 故障的預防針，不用你動手。
  6. 看到 SideStore 安裝成功！ 就完成了。它會提示你「開啟 SideStore 再重新整理一次」，那一步在 3.4 做。
檢查點：iPhone 主畫面出現 SideStore 圖示。先別急著打開——要先完成 Part 3 的信任設定。

PART 3 · 只做一次

iPhone 端：開發者模式、信任、LocalDevVPN

3.1 信任你的開發者憑證

  1. iPhone 開啟「設定」→「一般」→「VPN 與裝置管理」。
  2. 在「開發者 App」下面，點選對應你 Apple ID 的項目。
  3. 按信任，再確認一次。（這裡會顯示簽名帳號的電郵，只有你自己看得到。）
  4. iOS 18 或以上：確認的按鈕會順帶要求重新啟動 iPhone。按下去、輸入鎖機密碼，等它重開機再繼續。

3.2 開啟開發者模式

  1. 「設定」→「私隱與保安」→ 拉到最底找「開發者模式」。
  2. 開啟它。iPhone 會要求重新啟動，照做。
  3. 重啟解鎖後，再確認一次開啟並輸入密碼。
看不到開發者模式？先確定 SideStore 已經由 iloader 裝好，再重啟一次 iPhone。正常使用 GFlyer 期間，開發者模式要保持開啟。

3.3 安裝 LocalDevVPN

  1. 在 iPhone 開啟 LocalDevVPN 的 App Store 頁面並安裝（免費）。它從 App Store 安裝，不佔側載名額。
  2. 開啟它，首次會要求「加入 VPN 設定」→ 允許，輸入鎖機密碼。
  3. 裝置／目標 IP 保持預設 10.7.0.1，按連接。
檢查點：iPhone 控制中心顯示 VPN 已開啟。若你有其他 VPN（廣告攔截、公司 VPN、WireGuard 等），使用期間要先暫停它們，iOS 同一時間只認一個主要 VPN。

3.4 首次開啟 SideStore

  1. 確認 LocalDevVPN 已連接，開啟 SideStore。
  2. 登入你的 Apple ID（和 iloader 用的同一個）。
  3. 點畫面上的 7 DAYS 計數器做一次重簽，確認流程正常。
讓夜晚版自己更新SideStore 的設定裡有 beta 更新的選項，選 nightly 之後，新的夜晚版就會直接在 SideStore 內出現，不用再接電腦。
登入出錯？多數是 anisette 伺服器暫時故障：到 SideStore 設定換一個 Anisette Server 再試。

PART 4

安裝 GFlyer

用 iPhone 看這一頁？可以一鍵加入 直接叫 SideStore 加入上面那個來源，不用複製貼上。在電腦上按沒有作用。
在 SideStore 加入來源
  1. 開啟 SideStore → 點 Sources → 左上角＋。
  2. 貼上來源網址並確認：
    https://michaelcheung0125-svg.github.io/GFlyer-updates/altstore.json
  3. 來源裡會出現 GFlyer，點安裝。SideStore 會下載並用你的 Apple ID 簽名。
  4. 安裝時保持 LocalDevVPN 連接。若進度圈轉很久，先切回主畫面等 30 秒再看。
檢查點：開啟 GFlyer，畫面左上角顯示「裝置模式」；再到 App 的「設定 → 關於」看 App 版本。若顯示「預覽模式」代表裝到了不能控制全機定位的版本，請從上面的來源重新安裝。

備用：直接下載 IPA 手動安裝

來源加不進去、或想把安裝檔自己留一份時用這個。裝出來的 App 和上面完全一樣，差別只在於以後每次更新都要再手動來一次，所以能用 來源就用來源。

GFlyer iOS 0.6.5 未簽名 IPA · 9.4 MB
下載 IPA
  1. 在 iPhone 用 Safari 開上面的連結，檔案會存進「檔案」App 的「下載項目」。
  2. 開啟 SideStore → My Apps → 右上角 ＋。
  3. 選剛下載的 GFlyerIOS-版本-unsigned.ipa，保持 LocalDevVPN 連線， SideStore 會用你的 Apple ID 簽名安裝。
「未簽名」是正常的這份 IPA 本來就不帶任何人的簽名，所以不能直接點開安裝。 簽名是 SideStore 用你自己的 Apple ID 在手機上完成的，作者的簽名身分不在裡面。

PART 5 · 只做一次

GFlyer 首次設定：配對檔與第一次定位測試

全機定位模擬需要一份這部 iPhone 專屬的配對檔（Pairing File）。這是整個教學唯一比較「技術」的一步，跟著做即可。

兩份配對檔，不要混淆iloader 安裝 SideStore 時已經自動放好給 SideStore 用的那一份，你不用管。下面做的是給 GFlyer 用的另一份。兩者互不影響：日後 SideStore 出現 UDID 錯誤是它那一份的事，見 Part 11。

5.1 在電腦上建立配對檔

  1. 在電腦下載 idevice_pair--windows-x86_64.exe（約 38 MB），放在只有你能存取的資料夾。自己到 releases 頁 找的話，認檔名裡的 windows；其他是 macOS 與 Linux 的。
  2. iPhone 解鎖、停留在主畫面，用 USB 接上電腦；出現「信任此電腦？」就按信任。
  3. 開啟 idevice_pair，在裝置清單選你的 iPhone。
  4. 選 Remote pairing（不要選 Lockdown）。
  5. 按 Create 建立檔案，再按 Validate。驗證成功才繼續。
  6. 按 Save to file… 存到私人資料夾，保留原有副檔名（.mobiledevicepairing）。
配對檔是敏感檔案。它代表「一部被這 iPhone 信任的電腦」。不要上傳網盤共享、不要傳到群組、不能用別人的檔案。

5.2 把配對檔傳到 iPhone 並匯入

  1. 用 LocalSend（電腦版、iPhone 版，都免費，連同一 Wi-Fi）把配對檔傳到 iPhone，存進「檔案」App。USB 傳輸也可以；不要經公開連結或聊天群組。
  2. 開啟 GFlyer → 右上角齒輪進「設定」→「首次設定」→ 匯入 Pairing File。
  3. 在檔案選擇器選剛傳入的檔案，狀態變成「已匯入」。

5.3 第一次定位測試

  1. 回到地圖，模式選 傳送，在地圖點一個容易辨認的位置，按開始。
  2. 如果 LocalDevVPN 未連線，畫面會切換到 LocalDevVPN，約 1 秒後自動回到 GFlyer 繼續，你不用按任何東西。如 iPhone 問是否打開「LocalDevVPN」，按「打開」。若停在 LocalDevVPN 沒有回來，在那裡按連線（英文介面為 Connect），再自己切回 GFlyer。
  3. 首次會下載約 16 MB 的 DDI 並驗證——保持 GFlyer 在前景、不要斷網或關 VPN，等它完成。
  4. 顯示「裝置定位模擬中」後，打開 Apple 地圖：藍點應移到你選的位置。
  5. 回 GFlyer 再選另一個位置、再按開始 → Apple 地圖的藍點應跟著移動（證明連線可重用）。
  6. 按停止，顯示「已清除模擬位置」。
停止後 Apple 地圖還停在模擬位置？這是 iOS 的行為：它會沿用最後已知位置直到取得新的真實定位。要立刻還原見 Part 7 的「完整清除」。
用行動網絡（不是 Wi-Fi）的人建立第一條通道時，先開飛行模式再按開始成功率明顯較高，通道建立後再把飛行模式關掉。GFlyer 有一個畫面專門引導這串操作，見 Part 9。

  • 捷徑 GFlyer 飛航開、GFlyer 飛航關 已建立，並填進飛航模式輔助的兩個欄位

PART 7

日常使用：四種模式與收工還原

每次使用的順序（口訣）

GFlyer 選點 開始 停止

不用自己先開 LocalDevVPN：按開始時如果它未連線，GFlyer 會切換過去開啟，約 1 秒後自動回來繼續。

LocalDevVPN 要不要關？

不關也可以。LocalDevVPN 只處理 iPhone 自己的開發服務，不經過你的上網流量，一直開著不影響網速。想關的話有兩個方法，都在 GFlyer「設定」裡：

  • 「LocalDevVPN」區：看「VPN 狀態」，按關閉 LocalDevVPN（未連線時這個按鈕會變成「開啟 LocalDevVPN」）。模擬進行中不能關，要先按停止。
  • 「恢復」區：開啟「清除後同時關閉 LocalDevVPN」，之後按「完整清除模擬定位」時會一併關掉（見下面）。

按了之後畫面會切換到 LocalDevVPN，約 1 秒後自動回來。不想按開始時自動開 VPN，可在「LocalDevVPN」區關掉「按開始時自動開啟」。

四種模式

地圖下方的模式選擇器有四個選項。先選模式，再在地圖上點位置，最後按開始。

模式它做什麼怎樣選點
傳送直接跳到一個定點，不移動。點一個位置。要換地方就點另一處再按開始。
單點由目前位置走到一個目標點。點一個目標位置。
多點沿你排的路線逐段走完，可循環。依行走次序在地圖點多個位置，第一下點的就是第 1 點。點錯了按撤回（↶）逐點刪除，或按垃圾桶全部清除。
探索以選取位置為中心，持續螺旋式繞行。點一個中心位置。

速度、循環與進階選項

  • 速度：1.8–900 km/h。速度高於 20 km/h 時 App 會提醒你，部分遊戲會忽略太快的定位更新。
  • 循環路線：走完後自動再走一次。可選走回起點（沿路走回去）或直接返回（瞬移回起點）。
  • 進階播放選項（多點模式）：逐點傳送、每點停留秒數、到點繞圈、手動按「下一點」前進、開始前倒數、自動停止時間。倒數方便你先切回遊戲畫面。
  • 首次按開始時 iOS 會問定位權限，選「允許使用 App 期間」後再按一次開始。

搖桿

按地圖右側工具列的遊戲手掣圖示叫出搖桿，用手指推動位置。推得越遠走得越快，推到底會持續加速到上限。搖桿有自己的速度上限，和路線速度分開設定。

切到別的 App 也會繼續

路線與探索進行中可以切去其他 App，iOS 會顯示背景定位指示；按停止後 GFlyer 會立即結束背景活動。若 App 被系統中斷，下次開啟時會問你要不要恢復剛才的模擬（10 分鐘內有效）。

想讓其他 App 回到真實位置（完整清除）

一般的「停止」會保留通道方便下次快速開始，不保證其他 App 立刻看到真實位置。要真正還原用這個：

  1. GFlyer「設定」→「恢復」→ 按完整清除模擬定位。若同時開了「清除後同時關閉 LocalDevVPN」，清除成功後畫面會切換到 LocalDevVPN 關閉 VPN，再自動回來；清除失敗時會保留 VPN，方便你再按一次。
  2. App 會先把位置移回你上次的真實位置附近（畫面顯示「已移回真實位置附近，準備清除…」，約 2 秒），再清除、關閉模擬通道，然後自動驗證並告訴你結果（真實位置／仍是模擬座標／取不到定位）。先移回真實位置附近，是為了讓 Google 地圖等 App 較快回到真實位置，不會長時間停在遠方的模擬位置。
  3. 若顯示仍是模擬座標或取不到定位：開關一次飛行模式（LocalDevVPN 若還開著，先在「設定 → LocalDevVPN」按「關閉 LocalDevVPN」）。實機測試確認這一步之後其他 App 就會回到真實位置。

PART 9 · 選用

兩個選用捷徑：補錄步數與飛航模式

有兩件事 GFlyer 自己做不到，必須借用 iOS 內建的「捷徑」App，由捷徑用它自己的權限去做。全部都是選用的——不建捷徑一樣可以用 GFlyer，只是那兩件事要自己手動做。

功能為什麼要捷徑
補錄步數寫入「健康」App 需要 HealthKit 權限，免費 Apple ID 拿不到，SideStore 重簽時也會把它剝離。
切換飛行模式iOS 完全沒有讓 App 切換飛行模式的公開介面。

總共三個捷徑：補錄步數一個，飛航開與飛航關各一個。

8.1 捷徑「GFlyer 補錄步數」

  1. 開啟「捷徑」App，按右上角 ＋ 新增捷徑。
  2. 搜尋並加入動作「記錄健康樣本」。
  3. 把類型改成「步數」。
  4. 點數值欄位，選「捷徑輸入」。這一步最容易漏——漏了就會每次都寫入同一個固定值。
  5. 把捷徑命名為 GFlyer 補錄步數。
  6. 在捷徑的詳細資料裡關閉「執行前先詢問」，否則每次補錄都要多按一次確認。
  7. 回到 GFlyer →「設定」→「補錄步數」→「捷徑設定」，確認名稱和你剛才取的完全一致（連空格都要一樣）。

怎樣用

  • 設定 → 補錄步數：1000／3000／5000 或自訂步數，也看得到最近七天的紀錄。
  • 地圖工具列的步行圖示：一鍵補錄預設步數。要改這個數字，到「設定 → 補錄步數 → 地圖上的一鍵補錄」。

一鍵按鈕在捷徑成功回報過一次之前是灰色的，按下去會開啟設定頁而不是直接送出——這樣捷徑名稱打錯時，你會被帶到能修的地方，而不是跳去「捷徑」App 看一個找不到的錯誤。成功一次之後就永久解鎖。

8.2 捷徑「GFlyer 飛航開」與「GFlyer 飛航關」

實測在行動網絡下，先進飛行模式再建立模擬明顯比較穩定。完整順序是：

開飛行模式 開始模擬 關飛行模式

已經建立的通道可以從飛行模式延續到行動網絡回來之後，所以第 3 步不會中斷模擬。Wi-Fi 下通常不需要這串操作。

飛行模式只有開和關兩種，所以建兩個捷徑、各自只有一個動作，不需要「如果」判斷，也不需要選任何變數。

捷徑一：開啟

  1. 「捷徑」App → 右上角 ＋。
  2. 加入動作「設定飛航模式」。
  3. 確認它顯示的是「開啟」（預設就是）。
  4. 命名為 GFlyer 飛航開。

捷徑二：關閉

  1. 再新增一個捷徑。
  2. 同樣加入「設定飛航模式」。
  3. 點動作上的「開啟」，改成「關閉」。
  4. 命名為 GFlyer 飛航關。

最後把兩個捷徑的「執行前先詢問」都關掉。

在 GFlyer 裡怎樣用

  1. 點地圖右側工具列的飛機圖示，開啟「飛航模式輔助」。
  2. 開啟「用捷徑切換飛行模式」，把兩個名稱分別填進「開啟用」與「關閉用」。兩個都要填，少一個一鍵按鈕就不會亮。
  3. 畫面上三個步驟會自己推進：GFlyer 看得到網絡的實際狀態，所以你從控制中心手動切換飛行模式，畫面一樣會跟著跳。你不用再猜「現在可以關掉飛行模式了嗎」。

沒建捷徑的人這個畫面照樣可用，只是第 1、3 步要自己去控制中心切。

只有「關閉」會自動執行「模擬開始後自動關閉」預設開啟，但只作用在關閉方向。自動開啟飛行模式刻意不做：那一步中途失敗（捷徑被改名、你按了取消）會把你留在完全斷網的狀態而且不一定馬上發現；關閉方向失敗就只是維持現狀，自己關掉即可。
名稱必須完全一致GFlyer 是用名稱呼叫捷徑的。改了捷徑名稱就要同步改 GFlyer 裡的設定，反之亦然。特別留意全形空格和前後多餘的空白。

更新與 7 天重簽

App 更新（自動提示）

GFlyer 有新版時會自己跳出「有新版本」提示——按「用 SideStore 更新」即可，安裝時記得 LocalDevVPN 要連著。也可在「設定 → 軟體更新」手動檢查，那裡還有一個按鈕可以一鍵把更新來源加進 SideStore。

小知識：按更新後 SideStore 的清單可能不會顯示「有更新」，它是直接在背景安裝——回到 GFlyer 的「設定 → 關於」看到版本變了就是成功。

7 天簽名（自動重簽）

免費 Apple ID 的簽名約 7 天到期，但 SideStore 會在 iPhone 上自動重簽，正常情況你完全不用理會。若 App 突然打不開，開啟 LocalDevVPN → 開 SideStore → 點 7 DAYS 手動重簽一次即可。

SideStore 自己的更新

裝了夜晚版之後，在 SideStore 設定開啟 beta 更新並選 nightly，新的夜晚版就會直接在 SideStore 內出現，不用再接電腦。想改回穩定版才需要重新用 iloader。

TROUBLESHOOTING

疑難排解

安裝與 SideStore

症狀處理
SideStore 安裝／更新一直轉圈幾乎都是 LocalDevVPN 斷線（iOS 會自行終止 VPN，且不會報錯）。重新連接 VPN 再試；也可先切回主畫面等 30 秒——有時只是畫面凍結，其實已裝好。
SideStore 說「could not determine device UDID」
或 Health Check 顯示 RPPairing UDID not found		SideStore 讀的是它自己容器裡那份配對檔，不是你匯入 GFlyer 的那一份。用 iloader 重新配對後，一定要在 管理配對檔案Manage Pairing File 裡，按 SideStore 那一行的 放入Place，或用 Place In All Apps（這個字串未有中文，畫面上可能顯示英文）。只按安裝不會更新容器裡的舊檔案——實測就是這一步才修好的。
更新 LocalDevVPN 後突然無法重新整理LocalDevVPN 1.3 把 Tunnel IP 從 10.7.0.0/32 改成 10.7.1.1/32，和 SideStore 對不上。把 Tunnel IP 改回 10.7.0.0/32，或直接刪除 LocalDevVPN 重新安裝讓它帶入正確設定。
Health Check 顯示 Loaded (Connection down)配對檔本身沒問題，壞的是通道：先確認 LocalDevVPN 真的連著、沒有其他 VPN 搶佔，再檢查上一列的 Tunnel IP 問題。看到 UDID 字樣不要直接去重新產生配對檔，那通常不是原因。
夜晚版怪怪的，想換回穩定版用同一個 iloader，在 揀版本 改選 SideStore（穩定版） 重裝一次。資料一般會保留，但官方不保證——換之前先在 GFlyer 匯出備份檔。
加入來源顯示錯誤／看不到 GFlyer把來源移除，重新加入一次（SideStore 會快取來源內容）。
SideStore 登入失敗換一個 Anisette Server；不行就在伺服器設定重設 adi.pb，登出再登入。
iTunes／iloader 看不到 iPhone換 USB 插口或線；確認裝的是 Apple 網站版 iTunes；iPhone 解鎖後重新按「信任」。
7 天後 App 打不開開 LocalDevVPN → 開 SideStore → 點 7 DAYS 重簽。

GFlyer 與定位

症狀處理
GFlyer 顯示「預覽模式」裝到了不能控制全機定位的版本。從本教學的來源重新安裝。
配對檔 Create／Validate 失敗iPhone 保持解鎖並在主畫面；拔插 USB 重新信任；關閉其他佔用 USB 的工具；重新建立新檔案。
配對檔匯入失敗確認檔案是 idevice_pair 產生的原檔、副檔名沒被改掉（例如被改成 .txt）。
按開始後切到 LocalDevVPN，沒有自動回來在 LocalDevVPN 按連線（英文介面為 Connect），然後自己切回 GFlyer，模擬會自動繼續。
提示「LocalDevVPN 仍未連線」GFlyer 回來後等了約 10 秒，VPN 仍未連上。打開 LocalDevVPN 按連線，看到「已連線」後回 GFlyer 再按開始。若你有其他 VPN（廣告攔截、公司 VPN 等），先暫停它們。
「VPN 狀態」顯示「未安裝 LocalDevVPN」從 App Store 安裝 LocalDevVPN（見 Part 3 的 3.3）。
按開始後顯示通道／連線錯誤看「設定 → LocalDevVPN」的「VPN 狀態」是否「已連線」、目標 IP 是否 10.7.0.1；暫停其他 VPN；再用同一區的「測試 LocalDevVPN 通道」檢查。行動網絡下先開飛行模式再開始（Part 9）。
切去其他 App 後出現 BrokenPipe／Channel closedGFlyer 會自動清理並重連一次；再失敗就停止後重新開始。
停止後其他 App 仍顯示模擬位置正常現象。要立刻還原：「設定 → 恢復 → 完整清除模擬定位」，照結果指引關閉 LocalDevVPN 並開關一次飛行模式（Part 7）。
按「定位」說等不到新定位剛清除模擬後 iOS 需要時間取得真實定位。開關飛行模式、到收訊好的位置，或稍後再試。
DDI 下載或驗證失敗確認網絡正常後重按開始；App 會重新下載並以 SHA-256 驗證。

捷徑（Part 8 的兩個選用功能）

症狀原因
跳到「捷徑」App 顯示找不到捷徑名稱不一致。注意全形空格與前後空白。
每次都要多按一次確認捷徑詳細資料裡的「執行前先詢問」沒關。
補錄後步數不對數值欄位沒設成「捷徑輸入」，變成每次寫入同一個固定值。
補錄紀錄一直停在「未確認」捷徑跑完沒回到 GFlyer。要用 GFlyer 的按鈕啟動，不是在「捷徑」App 裡手動執行。
步行圖示是灰色的捷徑還沒成功跑過一次。按下去會開設定頁，先在那裡補錄成功一次。
飛航的一鍵切換按鈕是灰色的「開啟用」「關閉用」兩個名稱都要填，少一個就不算設定完成。
飛航輔助顯示「偵測中」只剩 VPN 之類的介面，判斷不出底層連線。三個步驟仍然可以直接按。

RULES & LIMITS

安全規則與已知限制

安全規則
  • 配對檔＝這部 iPhone 的信任憑證：只放在自己的裝置，絕不共享或公開上傳。
  • Apple ID 密碼與認證碼只輸入在自己電腦／手機上的官方流程。
  • 多人使用時：每人要用自己的 Apple ID 簽名、建立自己的配對檔。
已知限制
