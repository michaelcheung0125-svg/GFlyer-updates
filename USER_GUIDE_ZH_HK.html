GLOSSARY

名詞解釋：這些工具是什麼

先花兩分鐘認識會出場的角色，之後每一步你都會知道自己在做什麼。

側載（Sideload）

不經 App Store，把 App 裝進 iPhone。Apple 要求這種 App 用你自己的 Apple ID「簽名」，而免費帳號的簽名 7 天到期。

SideStore

常駐在 iPhone 上的「小型 App 商店」。它負責安裝 GFlyer、自動更新，以及每 7 天自動重簽——全部不用電腦。

iloader

Windows 上的一次性工具，用來把 SideStore 裝進 iPhone。之後就幾乎用不到電腦了。

LocalDevVPN

App Store 上的免費 App。它在 iPhone 內部建立一條「本機通道」，讓 SideStore 和 GFlyer 能連到 iPhone 自己的開發服務。它不是翻牆用的 VPN，不會改變你的上網地區。

Pairing File（配對檔）

這部 iPhone 信任電腦的憑證檔。GFlyer 的全機定位需要它。每部 iPhone 要建立自己的一份，屬於敏感檔案，不可給別人。

DDI（開發者磁碟映像）

約 16 MB 的 Apple 官方元件。GFlyer 第一次啟動定位時自動下載並驗證，之後保留在機內。

PART 1

準備清單

你需要

  • 一部 iPhone，iOS 17.4 或以上，已設定鎖機密碼
  • 一部 Windows 電腦（Windows 10/11），只在一次性設定時用到
  • 一條可傳資料的 USB 線（只能充電的線不行）
  • 你自己的 Apple ID（免費即可）
  • 網絡連線（首次會下載約 16 MB 的 DDI）
安全底線Apple ID 密碼與雙重認證碼只輸入在你自己電腦／手機上的官方流程（iloader / SideStore）。不要把密碼、憑證或配對檔交給任何人。

PART 2 · 只做一次

電腦端：裝好 Apple 元件與 SideStore

2.1 安裝 Apple 的 Windows 元件

iloader 依賴 Apple 的 USB 驅動程式，而驅動要靠 iTunes／iCloud 帶進來。注意：要用 Apple 網站版，不是 Microsoft Store 版。

  1. 如果電腦已裝了 Microsoft Store 版的 iTunes 或 iCloud，先到 Windows「已安裝的應用程式」把它們移除。
  2. 到 Apple 網站下載並安裝 Web 版 iTunes 與 Web 版 iCloud，然後重新啟動電腦。
  3. 開啟 iTunes，用 USB 線把 iPhone 接上電腦。
  4. iPhone 出現「信任此電腦？」→ 按信任，輸入 iPhone 密碼。
檢查點：iTunes 能看見你的 iPhone 才繼續。看不見的話，換一個 USB 插口或換一條線再試。

2.2 用 iloader 安裝 SideStore

  1. 從 SideStore 官方渠道下載 iloader（Windows 版）並開啟。
  2. 在 iloader 登入你自己的 Apple ID（含雙重認證）。
  3. 在裝置清單選擇你的 iPhone。
  4. 選 Install SideStore (Stable)，等待安裝完成。
檢查點：iPhone 主畫面出現 SideStore 圖示。先別急著打開——要先完成 Part 3 的信任設定。
3
PART 3 · 只做一次

iPhone 端：開發者模式、信任、LocalDevVPN

3.1 信任你的開發者憑證

  1. iPhone 開啟「設定」→「一般」→「VPN 與裝置管理」。
  2. 在「開發者 App」下面，點選對應你 Apple ID 的項目。
  3. 按信任，再確認一次。（這裡會顯示簽名帳號的電郵，只有你自己看得到。）

3.2 開啟開發者模式

  1. 「設定」→「私隱與保安」→ 拉到最底找「開發者模式」。
  2. 開啟它。iPhone 會要求重新啟動，照做。
  3. 重啟解鎖後，再確認一次開啟並輸入密碼。
看不到開發者模式？先確定 SideStore 已經由 iloader 裝好，再重啟一次 iPhone。正常使用 GFlyer 期間，開發者模式要保持開啟。

3.3 安裝 LocalDevVPN

  1. 在 iPhone 的 App Store 搜尋並安裝 LocalDevVPN（免費）。
  2. 開啟它，首次會要求「加入 VPN 設定」→ 允許。
  3. 裝置／目標 IP 保持預設 10.7.0.1，按連接。
檢查點：iPhone 控制中心顯示 VPN 已開啟。若你有其他 VPN（廣告攔截、公司 VPN、WireGuard 等），使用期間要先暫停它們，iOS 同一時間只認一個主要 VPN。

3.4 首次開啟 SideStore

  1. 確認 LocalDevVPN 已連接，開啟 SideStore。
  2. 登入你的 Apple ID（和 iloader 用的同一個）。
  3. 點畫面上的 7 DAYS 計數器做一次重簽，確認流程正常。
登入出錯？多數是 anisette 伺服器暫時故障：到 SideStore 設定換一個 Anisette Server 再試。

PART 4

安裝 GFlyer

  1. 開啟 SideStore → Browse → Sources → 右上角 ＋。
  2. 貼上來源網址並確認：
    https://michaelcheung0125-svg.github.io/GFlyer-updates/altstore.json
  3. 來源裡會出現 GFlyer，點安裝。SideStore 會下載並用你的 Apple ID 簽名。
  4. 安裝時保持 LocalDevVPN 連接。若進度圈轉很久，先切回主畫面等 30 秒再看。
檢查點：開啟 GFlyer，畫面左上角顯示「裝置模式」；再到 App 的「設定 → 關於」看 App 版本。若顯示「預覽模式」代表裝到了不能控制全機定位的版本，請從上面的來源重新安裝。

PART 5 · 只做一次

GFlyer 首次設定：配對檔與第一次定位測試

全機定位模擬需要一份這部 iPhone 專屬的配對檔（Pairing File）。這是整個教學唯一比較「技術」的一步，跟著做即可。

5.1 在電腦上建立配對檔

  1. 在電腦下載 idevice_pair（Windows x86_64 版），放在只有你能存取的資料夾。
  2. iPhone 解鎖、停留在主畫面，用 USB 接上電腦；出現「信任此電腦？」就按信任。
  3. 開啟 idevice_pair，在裝置清單選你的 iPhone。
  4. 選 Remote pairing（不要選 Lockdown）。
  5. 按 Create 建立檔案，再按 Validate。驗證成功才繼續。
  6. 按 Save to file… 存到私人資料夾，保留原有副檔名（.mobiledevicepairing）。
配對檔是敏感檔案。它代表「一部被這 iPhone 信任的電腦」。不要上傳網盤共享、不要傳到群組、不能用別人的檔案。

5.2 把配對檔傳到 iPhone 並匯入

  1. 用 LocalSend（電腦與 iPhone 都免費安裝，連同一 Wi-Fi）把配對檔傳到 iPhone，存進「檔案」App。USB 傳輸也可以；不要經公開連結或聊天群組。
  2. 開啟 GFlyer → 右上角齒輪進「設定」→「首次設定」→ 匯入 Pairing File。
  3. 在檔案選擇器選剛傳入的檔案，狀態變成「已匯入」。

5.3 第一次定位測試（單點）

  1. 確認 LocalDevVPN 已連接。
  2. GFlyer「設定」→ LocalDevVPN 區 → 按測試 LocalDevVPN 通道，應顯示「連線成功」。
  3. 回到地圖，模式選「傳送」，在地圖點一個容易辨認的位置，按開始。
  4. 首次會下載約 16 MB 的 DDI 並驗證——保持 GFlyer 在前景、不要斷網或關 VPN，等它完成。
  5. 顯示「裝置定位模擬中」後，打開 Apple 地圖：藍點應移到你選的位置。
  6. 回 GFlyer 再選另一個位置、再按開始 → Apple 地圖的藍點應跟著移動（證明連線可重用）。
  7. 按停止，顯示「已清除模擬位置」。
停止後 Apple 地圖還停在模擬位置？這是 iOS 的行為：它會沿用最後已知位置直到取得新的真實定位。要立刻還原見 Part 6 的「完整清除」。

PART 6

日常使用

每次使用的順序（口訣）

開 LocalDevVPN GFlyer 開始 GFlyer 停止 關 LocalDevVPN

重點：先開 VPN 才開始；先停止才關 VPN（清除定位需要通道還在）。

傳送模式

模式選「傳送」→ 點地圖 → 按「開始」。要換位置就點另一處再按開始。

路線模式

  • 模式選「單點」或「多點」，依行走次序在地圖點選位置。
  • 設定速度（1.8–900 km/h）；可開「循環路線」，選「走回起點」或「直接返回」。
  • 首次按開始時 iOS 會問定位權限，選「允許使用 App 期間」後再按一次開始。
  • 路線進行中可切去其他 App；iOS 會顯示背景定位指示。多點模式另有進階選項（逐點傳送、到點停留、繞圈、手動前進等）。

想讓其他 App 回到真實位置（完整清除）

  1. GFlyer「設定」→「恢復」→ 按完整清除模擬定位。
  2. App 會清除、關閉模擬通道，然後自動驗證並告訴你結果（真實位置／仍是模擬座標／取不到定位）。
  3. 若顯示仍是模擬座標：關閉 LocalDevVPN，然後開關一次飛行模式。實機測試確認這一步之後其他 App 就會回到真實位置。

PART 7 · 全自動

更新與 7 天重簽

App 更新（自動提示）

GFlyer 有新版時會自己跳出「有新版本」提示——按「用 SideStore 更新」即可，安裝時記得 LocalDevVPN 要連著。也可在「設定 → 軟體更新」手動檢查。

小知識：按更新後 SideStore 的清單可能不會顯示「有更新」，它是直接在背景安裝——回到 GFlyer 的「設定 → 關於」看到版本變了就是成功。

7 天簽名（自動重簽）

免費 Apple ID 的簽名約 7 天到期，但 SideStore 會在 iPhone 上自動重簽，正常情況你完全不用理會。若 App 突然打不開，開啟 LocalDevVPN → 開 SideStore → 點 7 DAYS 手動重簽一次即可。

TROUBLESHOOTING

疑難排解

症狀處理
SideStore 安裝／更新一直轉圈幾乎都是 LocalDevVPN 斷線（iOS 會自行終止 VPN，且不會報錯）。重新連接 VPN 再試；也可先切回主畫面等 30 秒——有時只是畫面凍結，其實已裝好。
加入來源顯示錯誤／看不到 GFlyer把來源移除，重新加入一次（SideStore 會快取來源內容）。
SideStore 登入失敗換一個 Anisette Server；不行就在伺服器設定重設 adi.pb，登出再登入。
GFlyer 顯示「預覽模式」裝到了預覽版。從本教學的來源重新安裝。
iTunes／iloader 看不到 iPhone換 USB 插口或線；確認裝的是 Apple 網站版 iTunes；重新按「信任」。
配對檔 Create／Validate 失敗iPhone 保持解鎖並在主畫面；拔插 USB 重新信任；關閉其他佔用 USB 的工具；重新建立新檔案。
配對檔匯入失敗確認檔案是 idevice_pair 產生的原檔、副檔名沒被改掉（例如被改成 .txt）。
按開始後顯示通道／連線錯誤確認 LocalDevVPN 已連接、目標 IP 是 10.7.0.1；暫停其他 VPN；用設定內「測試 LocalDevVPN 通道」檢查。
切去其他 App 後出現 BrokenPipe／Channel closedGFlyer 會自動清理並重連一次；再失敗就停止後重新開始。
停止後其他 App 仍顯示模擬位置正常現象。要立刻還原：「設定 → 恢復 → 完整清除模擬定位」，照結果指引關 VPN 並開關一次飛行模式。
按「定位」說等不到新定位剛清除模擬後 iOS 需要時間取得真實定位。開關飛行模式、到收訊好的位置，或稍後再試。
7 天後 App 打不開開 LocalDevVPN → 開 SideStore → 點 7 DAYS 重簽。
DDI 下載或驗證失敗確認網絡正常後重按開始；App 會重新下載並以 SHA-256 驗證。

RULES & LIMITS

安全規則與已知限制

安全規則
  • 配對檔＝這部 iPhone 的信任憑證：只放在自己的裝置，絕不共享或公開上傳。
  • Apple ID 密碼與認證碼只輸入在自己電腦／手機上的官方流程。
  • 多人使用時：每人要用自己的 Apple ID 簽名、建立自己的配對檔。
已知限制
  • GFlyer 是個人研究用途的側載 App，不在 App Store，也沒有任何反偵測功能——第三方 App 可以拒絕模擬位置；使用前留意該服務的條款與當地法律。
  • 免費 Apple ID 同時最多側載 3 個 App（SideStore 本身佔一個）。
  • iOS 大版本更新可能令配對檔或開發協定失效，屆時需要重新配對或等 App 更新。
  • 背景路線會增加耗電；iOS 在記憶體不足或 VPN 中斷時仍可能終止背景活動。
